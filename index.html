Your data is stored on this device. Export a backup regularly, especially before clearing Safari website data or changing phones.

Set up a Supabase project to sync between devices. Use a private project and enable email/password sign-in. Follow SETUP.md for the database and security policies.

Important iPhone notes

  • Install this app from its HTTPS website using Safari → Share → Add to Home Screen.
  • Open it once while online so the app and scanner library can be cached.
  • Allow camera access when Safari asks. Camera scanning requires HTTPS.
  • Offline scanning depends on the scanner library having been cached during the first online visit.
